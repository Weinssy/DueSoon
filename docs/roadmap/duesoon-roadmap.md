# DueSoon Roadmap

DueSoon is currently at **v1.4.0**.

## Core Philosophy
DueSoon is built on a strict "Deadline First" and minimal philosophy:
> "Deadline should be obvious. Everything else should stay quiet."

## Active Development: v1.x Series
The v1.x series focuses on refining the offline, single-device experience without adding unnecessary bloat.

### v1.5.0 (Planned)
- **Archive:** Ability to archive completed tasks to declutter the main database while retaining a historical record.
- **Statistics / Insights:** Basic offline insights into task completion rates and habits (e.g., tasks completed on time vs overdue).
- **Custom Reminders:** Extending the alarm manager to support user-defined reminder offsets, instead of relying purely on the automatic Smart Reminder logic.

## Future Horizons: v2.x Series
The v2.x series will focus on safely expanding DueSoon's capabilities beyond a single isolated device, while still adhering to the minimal, privacy-first principles.

### v2.0
- **Calendar Integration:** One-way sync to view your DueSoon deadlines natively inside Android calendar applications.
- **Cloud Sync (Opt-in):** End-to-end encrypted backup synchronization via user-controlled cloud providers (e.g., Google Drive), bypassing mandatory accounts.
- **Multi-Device Support:** Using cloud sync to provide basic, eventual consistency across multiple Android devices owned by the same user.
- **AI Assistance:** Minimal, fully optional on-device AI features to suggest realistic deadlines or break large tasks down into smaller steps.

---

## Explicitly Out of Scope
To preserve the minimal identity of DueSoon, the following features will **never** be added:
- Complex project management mechanics (Gantt charts, Kanban boards, story points).
- Mandatory user accounts or Login walls.
- Social/Collaborative features (assigning tasks to others, shared spaces).
- Gamification (points, badges, leaderboards).
- Real-time multiplayer synchronization.
